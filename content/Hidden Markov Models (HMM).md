> [!insight]
> A **Hidden Markov Model (HMM)** is a probabilistic model for **sequential data** where:
>
> - the system moves through a sequence of **hidden states**
> - we **cannot directly observe** those states
> - instead, each hidden state produces an **observable output**
>
> HMMs model **how hidden causes generate observable events over time**.

# The Core Idea

Imagine trying to determine today's weather **without looking outside**.

You cannot directly observe the weather.

Instead, every morning you see whether someone is carrying:

- ☂ Umbrella
- 🕶 Sunglasses
- 🧥 Jacket

These observations give clues about the hidden weather.

```text
Hidden State

Rainy ─────► Sunny ─────► Cloudy
   │                      │                       │
   ▼                      ▼                       ▼

Umbrella     Sunglasses        Jacket

Observable Outputs
```

You only observe the outputs.

The weather remains hidden.

This is exactly what an HMM models.

# Why is it called "Hidden"?

The actual process cannot be observed directly.

Instead we observe evidence generated by that process.

Examples

| Hidden State | Observable Evidence |
|--------------|--------------------|
| Weather | Umbrella, sunglasses |
| Spoken word | Audio waveform |
| Human intention | Body movement |
| Part of speech | Words in a sentence |
| DNA region | Nucleotide sequence |


# Two Fundamental Assumptions

## 1. Markov Property

The next state depends **only on the current state**.

Not the entire history.

$$
P(S_t \mid S_{t-1},S_{t-2},...,S_1)
=
P(S_t \mid S_{t-1})
$$

This is called the **first-order Markov assumption**.


## 2. Output Independence

The observation depends only on the current hidden state.

$$
P(O_t \mid S_1,...,S_t,O_1,...,O_{t-1})
=
P(O_t \mid S_t)
$$

# Components of an HMM

An HMM consists of five components.

## States

Hidden variables

$$
S=\{s_1,s_2,\ldots,s_N\}
$$

Example

```
Rainy
Sunny
Cloudy
```


## Observations

Visible outputs

$$
V=\{v_1,v_2,\ldots,v_M\}
$$

Example

```
Umbrella
Jacket
Sunglasses
```


## Transition Matrix

Probability of moving between hidden states.

$$
A=[a_{ij}]
$$

where

$$
a_{ij}=P(S_t=j \mid S_{t-1}=i)
$$

Example

| From | To | Probability |
|-------|----|------------|
| Rainy | Rainy | 0.7 |
| Rainy | Sunny | 0.2 |
| Rainy | Cloudy | 0.1 |


## Emission Matrix

Probability of producing an observation from a state.

$$
B=[b_j(k)]
$$

where

$$
b_j(k)
=
P(O_t=v_k \mid S_t=s_j)
$$

Example

```
Rainy
   │
   ├── Umbrella (0.8)
   ├── Jacket (0.15)
   └── Sunglasses (0.05)
```


## Initial State Distribution

Probability of starting in each state.

$$
\pi_i=P(S_1=i)
$$

---

# Complete HMM

The complete model is written as

$$
\lambda=(A,B,\pi)
$$

where

- $A$ = transition probabilities
- $B$ = emission probabilities
- $\pi$ = initial probabilities

# The Three Classical HMM Problems

Every Hidden Markov Model solves one of three problems.


## 1. Evaluation

**Question**

> How likely is this observation sequence?

Given

- model
- observations

Compute

$$
P(O|\lambda)
$$

Solved using

- Forward Algorithm


## 2. Decoding

**Question**

> What hidden states most likely produced these observations?

Given

```
Umbrella
Umbrella
Sunglasses
```

Infer

```
Rainy
Rainy
Sunny
```

Solved using

- Viterbi Algorithm


## 3. Learning

**Question**

> How do we estimate the model parameters?

Unknown

- transition probabilities
- emission probabilities

Learn

$$
A,B,\pi
$$

Solved using

- Baum–Welch Algorithm (Expectation Maximization)

# Why HMMs Became Important

HMMs became the standard probabilistic model for sequential data because they can naturally model:

- temporal dependencies
- uncertainty
- noisy observations
- hidden processes

Applications included

- Speech recognition
- Handwriting recognition
- Natural language processing
- Bioinformatics
- Gesture recognition
- Activity recognition
- Finance

Before deep learning, HMMs dominated speech recognition for nearly three decades.

---

# Advantages

✅ Interpretable

✅ Probabilistic

✅ Handles noisy observations

✅ Excellent for sequential data

✅ Efficient dynamic programming algorithms

---

# Limitations

❌ First-order Markov assumption

❌ Limited long-term memory

❌ Linear state transitions

❌ Manual feature engineering often required

❌ Deep learning models outperform HMMs on many modern tasks

# Key Takeaways

> [!summary]
>
> - HMMs model **hidden states** that generate observable outputs.
> - They assume the **next state depends only on the current state**.
> - Observations depend only on the **current hidden state**.
> - The model is defined by:
>   - Initial probabilities ($\pi$)
>   - Transition matrix ($A$)
>   - Emission matrix ($B$)
> - The three classical HMM problems are:
>   - Evaluation
>   - Decoding
>   - Learning
> - Core algorithms:
>   - Forward
>   - Viterbi
>   - Baum–Welch
> - HMMs were the foundation of modern sequence modeling before deep learning.
